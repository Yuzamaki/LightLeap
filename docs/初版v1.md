# LightLeap MVP 实现计划

## Context

为青少年 AI 健康管理 App「轻跃 LightLeap」搭建 MVP 后端。MVP 聚焦 6 个核心模块：饮食记录（含红黄绿灯）、运动记录、喝水追踪、体重趋势、仪表盘、AI 对话教练、食物拍照识别。


## 关键架构决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 数据库 | **SQLite**（开发期） | 零配置，SQLAlchemy 一键切 PostgreSQL |
| 缓存/会话 | **内存**（开发期） | MVP 不过早引入 Redis，FastAPI 内置足够 |
| LLM 提供商 | **OpenAI 兼容 API** | 配置化切换 OpenAI/DeepSeek/GLM |
| 食物识别 | **占位（不实现）** | 先留接口，后续可选 API 或自训 YOLO |
| 身份认证 | **简单手机号注册 + JWT** | MVP 不做验证码，用模拟方式 |
| 文件存储 | **本地磁盘** | MVP 阶段没必要上 OSS |

## 实施步骤（按顺序）

### Step 1: 安装新增依赖

```bash
pip install "python-jose[cryptography]" passlib[bcrypt] openai python-multipart alembic pytest
```

### Step 2: 搭建基础骨架（app/config.py, app/database.py, app/main.py, app/dependencies.py）

- `config.py`: Settings 类，读取 OPENAI_API_KEY, LLM_BASE_URL, LLM_MODEL, SECRET_KEY 等
- `database.py`: SQLAlchemy async engine + sessionmaker（使用 aiosqlite）
- `main.py`: FastAPI app，注册所有 router，配置 CORS
- `dependencies.py`: `get_db()`, `get_current_user(token)`

### Step 3: 用户模型 + 认证（models/user.py, schemas/user.py, services/auth_service.py, routers/auth.py）

- User 表：id, nickname, phone_hash, age_group, gender, height_cm, weight_kg, fitness_level, goal, created_at
- 注册: POST /api/v1/auth/register
- 登录: POST /api/v1/auth/login（手机号 + 模拟验证码 000000）
- JWT token 签发与验证
- GET /api/v1/profile, PUT /api/v1/profile

### Step 4: 饮食记录模块（models/meal.py, schemas/meal.py, services/meal_service.py, routers/meals.py）

- MealRecord 表：id, user_id, meal_type(早/午/晚/加餐), recorded_at, foods(JSON), photo_url
- 红黄绿灯算法（基于食物分类，参考规划书 Python 代码）
- 内置食物数据库 ~100 种（utils/food_data.py）
- API: CRUD /meals, GET /meals/search?q=xxx, GET /meals/summary

### Step 5: 运动记录模块（models/exercise.py, schemas/exercise.py, services/exercise_service.py, routers/exercises.py）

- ExerciseRecord 表：id, user_id, exercise_type, duration_min, calories(可选), notes, recorded_at
- 运动类型枚举：跑步/走路/跳绳/篮球/游泳/羽毛球/俯卧撑/仰卧起坐/其他
- API: CRUD /exercises, GET /exercises/summary

### Step 6: 喝水追踪模块（models/water.py, schemas/water.py, services/water_service.py, routers/water.py）

- WaterRecord 表：id, user_id, cups, recorded_at
- 目标：体重×30ml + 运动加成
- API: POST /water（+1杯）, GET /water/today（今日进度+环形图数据）

### Step 7: 体重趋势模块（models/weight.py, schemas/weight.py, services/weight_service.py, routers/weight.py）

- WeightRecord 表：id, user_id, weight_kg, recorded_at
- 7日移动平均平滑算法（参考规划书）
- API: POST /weight, GET /weight/trend?days=30

### Step 8: 仪表盘模块（services/dashboard_service.py, routers/dashboard.py）

- GET /dashboard/today：聚合今日饮食(红黄绿比例)、运动总时长、喝水进度、体重趋势、连续打卡天数

### Step 9: AI 对话教练（services/ai_coach.py, services/safety_filter.py, routers/ai.py）

- **ai_coach.py**: 
  - 构建 System Prompt（基于规划书的 Prompt 模板，注入用户上下文）
  - 维护对话历史（最近 10 轮）
  - 调用 OpenAI 兼容 API（支持流式 SSE）
- **safety_filter.py**:
  - 输入过滤：检测节食/催吐/自残等关键词
  - 输出过滤：检测 LLM 回复中的不安全内容
  - 异常模式告警日志
- API: POST /ai/chat（非流式）, GET /ai/chat/stream（SSE 流式）

### Step 10: 食物拍照识别（占位）

- 仅创建 `routers/ai.py` 中的路由骨架，`services/food_vision.py` 为占位文件
- API `POST /ai/meal-recognize` 返回 `{"status": "not_implemented", "message": "食物拍照识别功能开发中"}`

### Step 11: 测试与验证

- tests/conftest.py：测试用 DB + 测试 client fixture
- test_auth.py：注册/登录/profile
- test_meals.py：CRUD + 搜索 + 红绿灯
- test_ai.py：对话安全过滤 + 食物识别

### Step 12: 生成 requirements.txt + .env.example

## 验证方式

1. `uvicorn app.main:app --reload` 启动服务
2. 访问 `http://localhost:8000/docs` 查看 Swagger 文档
3. 完整流程测试：注册 → 登录 → 记录饮食 → 记录运动 → 记录喝水 → 查看仪表盘 → AI 对话
4. `pytest tests/ -v` 跑单元测试
